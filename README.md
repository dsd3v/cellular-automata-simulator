## Cellular Automata Simulator

Cellular Automata Simulations with modifiable settings/controls.

- 1D: Elementary Cellular Automaton - Binary Rulesets [0-255]
- 2D: Game of Life - B3 / S2-3
- 3D: Game of Life - B4 / S4-5

View on the web: [https://dsd3v.github.io/cellular-automata-simulator](https://dsd3v.github.io/cellular-automata-simulator)

#### Technologies Used:

- HTML, CSS, & JavaScript.
- Hosted on GitHub Pages.
